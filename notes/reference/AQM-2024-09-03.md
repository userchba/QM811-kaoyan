## 第一章：量子力学基本概念、理论与数学方法

### §1.1 基本原理

#### 原理1：态矢量

微观系统的状态由 **Hilbert空间** 中的矢量 ∣ψ(t)⟩描述。

- **Hilbert空间**：定义了内积运算的完备复数线性空间。

#### 原理2：观测量与算符

微观系统的力学量用 Hilbert 空间中的 **厄米算符 (Hermitian Operator)** A^描述。

- **本征值方程**：A^∣ai⟩=ai∣ai⟩
- 力学量的可测值仅限于其本征值 ai。
- **完备性**：态矢量可展开为 ∣ψ(t)⟩=∑ici(t)∣ai⟩。
- **概率诠释**：∣ci∣2给出测量得到 ai的概率（需满足归一化 ∑i∣ci∣2=1）。
- **波包坍缩 (Collapse)**：测量后得到 ai，系统态变为对应的本征态 ∣ai⟩。

#### 原理3：对易关系 (正则量子化)

直角坐标下，坐标算符与动量算符的对易关系为：

```
[r^i,p^j]=iℏδij,(i,j=x,y,z)
```

其中 δij为 Kronecker delta 符号。

```
[r^i,r^j]=[p^i,p^j]=0
```

#### 原理4：时间演化

态矢量随时间演化遵循 **薛定谔方程**：

```
iℏ∂t∂∣ψ(t)⟩=H^∣ψ(t)⟩
```

其中 H^为系统的哈密顿算符。

#### 原理5：全同粒子

全同粒子系统的波函数，对任意一对粒子交换具有对称性或反对称性：

- **玻色子 (Boson)**：对称波函数（自旋为 ℏ的整数倍），服从 Bose-Einstein 统计。
- **费米子 (Fermion)**：反对称波函数（自旋为 ℏ的半奇数倍），服从 Fermi-Dirac 统计。

### §1.2 Dirac 记号与常用算符

#### 1. 右矢 (Ket) 与左矢 (Bra)

- **右矢**：表示态矢量，如 ∣ψ(t)⟩,∣ϕ⟩,∣ai⟩,∣x⟩,∣p⟩,∣ℓ,m⟩。
- **左矢**：表示对偶矢量，如 ⟨ψ(t)∣,⟨ϕ∣,⟨ai∣。
- **对应关系**：∣ψ⟩↔⟨ψ∣；若 ∣ψ′⟩=λ∣ψ⟩，则 ⟨ψ′∣=λ∗⟨ψ∣。

#### 2. 内积 (Inner Product)

- 定义：⟨ϕ∣ψ⟩(复数)。
- **性质**：⟨ϕ∣ψ⟩=⟨ψ∣ϕ⟩∗(复共轭)。⟨ψ∣ψ⟩≥0，且 ⟨ψ∣ψ⟩=1时为归一化态。正交性：若 ⟨ϕ∣ψ⟩=0，则两态正交。Schwarz 不等式：∣⟨ϕ∣ψ⟩∣2≤⟨ϕ∣ϕ⟩⟨ψ∣ψ⟩。

#### 3. 外积 (Outer Product)

- 形式：∣ϕ⟩⟨ψ∣，它是一个**算符**。
- **作用**：(∣ϕ⟩⟨ψ∣)∣χ⟩=⟨ψ∣χ⟩∣ϕ⟩。
- **投影算符**：P^ϕ=∣ϕ⟩⟨ϕ∣。作用：P^ϕ∣χ⟩=⟨ϕ∣χ⟩∣ϕ⟩。

#### 4. 线性与反线性算符

- **线性算符** A^：A^(c1∣ψ1⟩+c2∣ψ2⟩)=c1A^∣ψ1⟩+c2A^∣ψ2⟩。
- **反线性算符** B^：B^(c1∣ψ1⟩+c2∣ψ2⟩)=c1∗B^∣ψ1⟩+c2∗B^∣ψ2⟩。

#### 5. 厄米共轭与厄米算符

- **厄米共轭** A^†：满足 ⟨ϕ∣A^†∣ψ⟩=⟨ψ∣A^∣ϕ⟩∗。性质：(A^B^)†=B^†A^†；(∣ψ⟩⟨ϕ∣)†=∣ϕ⟩⟨ψ∣。
- **厄米算符 (Hermitian)**：A^†=A^。本征值为实数。不同本征值的本征态正交：⟨ai∣aj⟩=δij。任意算符可分解为厄米部分与反厄米部分之和：A^=21(A^+A^†)+21(A^−A^†)。
- **反厄米算符**：A^†=−A^。

#### 6. 幺正算符 (Unitary Operator)

- **定义**：U^†=U^−1。
- **性质**：保持内积不变。`∣ψ′⟩=U^∣ψ⟩,⟨ψ′∣ϕ′⟩=⟨ψ∣ϕ⟩`保持矢量模长不变。

#### 7. 反幺正算符 (Antiunitary Operator)

- **定义**：反线性且满足 ⟨u^ψ∣u^ϕ⟩=⟨ϕ∣ψ⟩=⟨ψ∣ϕ⟩∗。
- 通常写作 u^=U^K^（K^为复共轭算符）。

### 8. 正规算符 (Normal Operator)

**定义**：满足以下对易关系的算符 N^：

```
[N^,N^†]=0
```

**常见特例**：

- **厄米算符**：本征值 λ0为实数。
- **反厄米算符**：本征值 λ0为纯虚数。
- **幺正算符**：本征值 λ0为模为 1 的复数 (eiϕ)。

**正交性**：

```
⟨λn∣λm⟩=δnm
```

**谱展开 (Spectral Expansion)**：

```
N^=n∑λn∣λn⟩⟨λn∣
```

------

### 9. 等距算符 (Isometric Operator) V^

**定义**：

```
V^†V^=1,但V^V^†=1
```

**性质分析**：

1. **保内积（正向）**：设 V^∣ψ⟩=∣ψ′⟩, V^∣φ⟩=∣φ′⟩，则：`⟨φ′∣ψ′⟩=⟨φ∣V^†V^∣ψ⟩=⟨φ∣ψ⟩`内积保持不变。
2. **不保内积（反向）**：设 V^†∣ψ⟩=∣ψ~⟩, V^†∣φ⟩=∣φ~⟩，则：`⟨φ~∣ψ~⟩=⟨φ∣V^V^†∣ψ⟩=⟨φ∣ψ⟩`内积发生改变（通常等于 ⟨φ∣ψ⟩∗或其他值）。

> ⚠️ **注意**：等距变换不等同于酉变换！等距变换不直接对应于物理态的变换（因为不是满射）。

## §1.3 表象与表象变换

### 1. A-表象 (离散谱)

设厄米算符 A^(A^†=A^) 具有分立谱：

```
A^∣ai⟩=ai∣ai⟩(i=1,2,…,n)
```

满足正交归一性：

```
⟨ai∣aj⟩=δij
```

#### 完备性与态矢量展开

任意态矢量 ∣ψ(t)⟩可展开为：

```
∣ψ(t)⟩=i=1∑nCi(t)∣ai⟩
```

代入左矢 ⟨aj∣可得展开系数：

```
Ci(t)=⟨ai∣ψ(t)⟩
```

因此完备性关系可写为外积形式：

```
i=1∑n∣ai⟩⟨ai∣=1
```

#### 态矢量的矩阵表示

在 A-表象中，态矢量 ∣ψ(t)⟩表示为一个列矩阵（坐标）：

```
∣ψ(t)⟩≐⟨a1∣ψ(t)⟩⟨a2∣ψ(t)⟩⋮⟨an∣ψ(t)⟩=C1(t)C2(t)⋮Cn(t)
```

其中 ∣Ci(t)∣2代表测量得到 ai的概率。

左矢 ⟨ψ(t)∣表示为行矩阵：

```
⟨ψ(t)∣≐(⟨a1∣ψ(t)⟩∗,⟨a2∣ψ(t)⟩∗,…,⟨an∣ψ(t)⟩∗)≡ψ†(t)
```

#### 本征矢的表示

算符 A^的另一个本征态 ∣bn⟩在 A-表象中表示为：

```
∣bn⟩≐⟨a1∣bn⟩⟨a2∣bn⟩⋮⟨an∣bn⟩,⟨bn∣≐(⟨a1∣bn⟩∗,…,⟨an∣bn⟩∗)
```

#### 算符的矩阵表示

算符 F^在 A-表象中的矩阵元定义为：

```
Fij=⟨ai∣F^∣aj⟩
```

矩阵形式为：

```
F^≐F11F21⋮Fn1F12F22⋮Fn2⋯⋯⋱⋯F1nF2n⋮Fnn≡F
```

**厄米共轭的矩阵关系**：

```
Fji∗=Fij†⇒F†=(FT)∗
```

即厄米共轭等于转置加复共轭。

**特殊算符的矩阵形式**：

- **厄米算符**：F†=F（若矩阵元为实数，则为实对称矩阵）。
- **幺正算符**：F†=F−1（若矩阵元为实数，则为正交矩阵）。
- **A^自身的矩阵**：由于 A^∣ai⟩=ai∣ai⟩，`Aij=⟨ai∣A^∣aj⟩=aj⟨ai∣aj⟩=ajδij`故 A^在其自身表象中是对角矩阵：`A=a10⋮00a2⋮0⋯⋯⋱⋯00⋮an`其谱表示为：A^=∑iai∣ai⟩⟨ai∣。

#### 外积的矩阵表示

外积 ∣φ⟩⟨ψ∣对应的矩阵 F~为：

```
F~ij=⟨ai∣φ⟩⟨ψ∣aj⟩=⟨ai∣φ⟩⟨aj∣ψ⟩∗
```

矩阵形式为列向量乘以行向量（外积运算）：

```
F~=⟨a1∣φ⟩⋮⟨an∣φ⟩(⟨a1∣ψ⟩∗,⋯,⟨an∣ψ⟩∗)=φψ†
```

#### 平均值的矩阵表示

算符 F^在态 ∣ψ(t)⟩中的平均值：

```
⟨F^⟩=⟨ψ(t)∣F^∣ψ(t)⟩=ψ†(t)Fψ(t)
```

#### 本征值方程的矩阵形式

求解 F^∣f⟩=f∣f⟩等价于求解矩阵本征值方程：

```
Ff=ff
```

其中 f=⟨a1∣f⟩⋮⟨an∣f⟩。

存在非平庸解的条件是久期方程 (Secular Equation) 成立：

```
det(F−f1)=0
```

即：

```
F11−fF21⋮Fn1F12F22−f⋮Fn2⋯⋯⋱⋯F1nF2n⋮Fnn−f=0
```

### 2. 坐标表象与动量表象 (连续谱)

#### 坐标表象 (一维)

**本征值方程**：

```
x^∣x⟩=x∣x⟩
```

**正交性**：

```
⟨x′∣x⟩=δ(x−x′)
```

*推导简述*：利用 ⟨x′∣x^∣x⟩=x⟨x′∣x⟩=x′⟨x′∣x⟩，得 (x−x′)⟨x′∣x⟩=0。结合 xδ(x)=0，得出比例关系，取归一化系数即得。

**完备性**：

```
∫−∞∞dx∣x⟩⟨x∣=1
```

**波函数表示**：

```
∣ψ(t)⟩=∫−∞∞dx∣x⟩⟨x∣ψ(t)⟩=∫−∞∞dxψ(x,t)∣x⟩
```

其中 ψ(x,t)=⟨x∣ψ(t)⟩即为坐标空间波函数。

∣ψ(x,t)∣2表示 t时刻在 x处找到粒子的概率密度。

**归一化条件**：

```
⟨ψ(t)∣ψ(t)⟩=∫−∞∞dxψ∗(x,t)ψ(x,t)=∫−∞∞dx∣ψ(x,t)∣2=1
```

**内积表示**：

```
⟨φ(t)∣ψ(t)⟩=∫−∞∞dxφ∗(x,t)ψ(x,t)
```

#### Dirac δ-函数性质

1. 奇偶性：δ(x)=δ(−x)
2. 筛选性：xδ(x)=0
3. 微分性质：xdxdδ(x)=−δ(x)
4. 积分定义：∫−∞∞dxδ(x)=1(区间包含原点)
5. 采样性质：∫−∞∞dxf(x)δ(x)=f(0)
6. 复合性质：∫−∞∞dxδ(x−a)δ(x−b)=δ(a−b)
7. 缩放性质：δ(ax)=∣a∣1δ(x)

**初等函数表示**：

(a) Lorentz型：δ(x)=limϵ→0π1x2+ϵ2ϵ

(b) 积分型：δ(x)=2π1∫−∞∞dkeikx

(c) Gauss型：δ(x)=limϵ→0πϵ1exp(−ϵx2)

#### 坐标算符的矩阵表示

坐标算符 x^n的矩阵元：

```
⟨x∣x^n∣x′⟩=xn⟨x∣x′⟩=xnδ(x−x′)
```

其谱表示为：

```
x^n=∫dx∣x⟩xn⟨x∣
```

### 1. 坐标表象中动量算符的矩阵元

动量算符 p^在坐标表象 {∣x⟩}下的矩阵元定义为：

```
Pxx′=⟨x∣p^∣x′⟩=−iℏ∂x∂δ(x−x′)
```

**证明**：

利用基本对易关系 [x^,p^]=iℏ，左乘 ⟨x∣，右乘 ∣x′⟩：

```
⟨x∣[x^,p^]∣x′⟩=iℏ⟨x∣x′⟩
```

左侧展开：

```
⟨x∣(x^p^−p^x^)∣x′⟩=(x−x′)⟨x∣p^∣x′⟩
```

右侧为：

```
iℏδ(x−x′)
```

因此：

```
(x−x′)⟨x∣p^∣x′⟩=iℏδ(x−x′)
```

结合分布导数性质 (x−x′)∂x∂δ(x−x′)=−δ(x−x′)，可得：

```
⟨x∣p^∣x′⟩=−iℏ∂x∂δ(x−x′)
```

### 7. 动量表象

**(a) 基本性质**

动量本征态 ∣p⟩满足 p^∣p⟩=p∣p⟩。

- **正交性**：⟨p′∣p⟩=δ(p′−p)
- **完备性**：∫−∞∞dp∣p⟩⟨p∣=1

态矢量在动量表象的展开：

```
∣ψ(t)⟩=∫−∞∞dp∣p⟩⟨p∣ψ(t)⟩=∫−∞∞dp∣p⟩ψ(p,t)
```

其中 ψ(p,t)=⟨p∣ψ(t)⟩为动量空间波函数，∣ψ(p,t)∣2表示动量为 p的概率密度。

**(b) 动量表象中的算符矩阵元**

- **坐标算符**：`xpp′=⟨p∣x^∣p′⟩=iℏ∂p∂δ(p−p′)`
- **坐标算符 n次幂**：`xpp′n=⟨p∣x^n∣p′⟩=(iℏ∂p∂)nδ(p−p′)`
- **动量算符 n次幂**：`Ppp′n=⟨p∣p^n∣p′⟩=pnδ(p−p′)`

**(c) 坐标与动量表象的波函数关系**

## §1.4 一维线性谐振子的代数解法

### 1. 产生与湮灭算符的定义

引入无量纲算符：

```
⎩⎨⎧a^=2ℏmω(x^+mωip^)a^†=2ℏmω(x^−mωip^)
```

a^与 a^†互为厄米共轭，**不是厄米算符**。

**逆变换**：

```
⎩⎨⎧x^=2mωℏ(a^+a^†)p^=i2mℏω(a^†−a^)
```

------

### 2. 对易关系

利用 [x^,p^]=iℏ，可得：

```
[a^,a^†]=1
```

且 N^=a^†a^为厄米算符（粒子数算符）。

------

### 3. 粒子数算符 N^的本征值与本征态

本征方程：N^∣n⟩=n∣n⟩，⟨n∣n⟩=1。

**(a) 本征值 n的非负性**

由 ⟨n∣N^∣n⟩=n⟨n∣n⟩=n，且 ⟨n∣a^†a^∣n⟩=∥a^∣n⟩∥2≥0，得 n≥0。

**(b) 递推关系与本征值谱**

利用对易关系可证：

```
N^(a^†)m=(a^†)m(N^+m)
```

作用于基态 ∣0⟩（满足 a^∣0⟩=0）：

```
N^(a^†)m∣0⟩=m(a^†)m∣0⟩
```

表明 (a^†)m∣0⟩是 N^本征值为 m的本征态。进一步由 ⟨n∣(a^†)ma^m∣n⟩=n(n−1)⋯(n−m+1)≥0，推得 n必须为非负整数：

```
n=0,1,2,…
```

**(c) 归一化本征态**

```
∣n⟩=n!1(a^†)n∣0⟩
```

满足正交归一性 ⟨n′∣n⟩=δn′n和完备性 n=0∑∞∣n⟩⟨n∣=1。

------

### 4. 产生与湮灭算符的作用

```
a^†∣n⟩a^∣n⟩a^∣0⟩=n+1∣n+1⟩=n∣n−1⟩=0(上升算符)(下降算符，n>0)
```

------

### 5. 哈密顿量与能谱

```
H^=ℏω(a^†a^+21)=ℏω(N^+21)
```

本征能量：

```
En=(n+21)ℏω,n=0,1,2,…
```

- **基态**：∣0⟩，E0=21ℏω
- **激发态**：∣n⟩，En−E0=nℏω

### 6. 坐标表象下的谐振子波函数

**(a) 基态波函数 ψ0(x)=⟨x∣0⟩**

由 a^∣0⟩=0，代入坐标表象：

```
2ℏmω(x+mωi(−iℏ∂x∂))ψ0(x)=0
```

化简为：

```
(x+mωℏ∂x∂)ψ0(x)=0⇒dxdψ0=−ℏmωxψ0
```

解得：

```
ψ0(x)=Aexp(−21ℏmωx2)=Aexp(−2x02x2)
```

由归一化 ∫−∞∞∣ψ0(x)∣2dx=1得：

```
A=(πℏmω)1/4=π1/4x01
```

**(b) 激发态波函数**

利用 ⟨x∣a^†=2ℏmω(x−x02∂x∂)⟨x∣和 ∣n⟩=n!1(a^†)n∣0⟩，得：

```

```

其中 ξ=x/x0，Hn(ξ)=(−1)neξ2dξndne−ξ2为 Hermite 多项式。
