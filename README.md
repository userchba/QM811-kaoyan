# 中科院 811 量子力学考研真题集

这是一个关于中国科学院大学「811 量子力学」历年考研真题收集整理的仓库。

## 内容概览

| 类别 | 说明 |
| ---- | ---- |
| 覆盖年份 | **2003 – 2026**（2006 年含甲/乙卷 A、B 共四份，2007 年含 A、B 卷） |
| 官方卷 | 2013、2020、2021 |
| 校对完成 | 2010 – 2016（含简明参考答案） |
| 排版 | LaTeX（`xelatex`），含封面、说明、目录、页眉页脚 |
| 许可 | [CC BY-NC-SA 4.0](LICENSE)（署名-非商业性使用-相同方式共享） |

> 各年份的启用列表以 [`811.tex`](811.tex) 中的 `\include` 为准，本文件不再重复维护，
> 以免两处不同步。

## 下载

编译好的 PDF 见 [Releases](https://gitee.com/ylxdxx/QM811-kaoyan/releases)，提供两个版本：

| 文件 | 说明 |
| ---- | ---- |

| `811_noanswer.pdf` | 纯试题版（隐藏全部答案，便于先做题后对答案） |

## 编译

必须使用 `xelatex`，并需多遍编译以正确生成目录页码与交叉引用：

```bash
./build.sh            # 一键生成含答案版与纯试题版
./build.sh answers    # 只生成 811.pdf
./build.sh noanswer   # 只生成 811_noanswer.pdf
```

> `build.sh` 会自动迭代编译至目录收敛，并检查 `!` 级错误；
> 它通过临时副本切换 `811.tex` 中的 `\answertrue` / `\answerfalse`，不会改动源文件。

也可以手动编译单个版本：

```bash
xelatex 811.tex && xelatex 811.tex && xelatex 811.tex
```

## 目录结构

```
811.tex          主文档入口（控制启用哪些年份、是否显示答案）
style.cls        真题集文档类（版式、页脚、目录页码）
build.sh         构建脚本
1/               各年份真题源码 + cover/说明/目录
picture/svg/     SVG 原图（编译时自动在 svg-inkscape/ 生成缓存）
notes/           量子力学复习讲义（与真题集独立，见 notes/README.md）
```
